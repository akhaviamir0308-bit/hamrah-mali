# همراه مالی — فاز تکمیل مدیریت هزینه‌های آینده

`schemaVersion: 4`

## اجرا

```bash
cd hamrah-mali
python3 -m http.server 8080
```

http://localhost:8080

## معماری

- **هزینه دوره‌ای** مستقل است (ثبت / تأمین / پرداخت جدا).
- **صندوق هدفمند** اختیاری است.
- اتصال هزینه ↔ صندوق **اختیاری و یک‌به‌یک**.
- بدون موعد: سهم ماهانه خودکار پیشنهاد نمی‌شود؛ می‌توان `monthlyOverride` گذاشت.

## قابلیت‌ها

### هزینه‌های دوره‌ای
ثبت، تکرار، موعد، اولویت، توقف، پرداخت، تأمین مستقل، اتصال اختیاری، ماشین‌حساب هزینه بزرگ

### صندوق‌ها
ساخت، واریز/برداشت، تاریخچه، پیشرفت، سهم ماهانه، قطع امن لینک هنگام حذف

### بودجه آینده‌نگر
درآمد − هزینه جاری − تعهدات آینده = مانده  
بدون دوباره‌شماری موارد متصل · هشدار کسری · پیشنهاد کاهش سهم

### راهنما
هشت فصل «راهنمای همراه مالی» (`#guide`) + راهنمای کوتاه contextual در هر بخش

## فایل‌ها

- `js/future.js` — منطق آینده، بودجه، راهنما
- `js/core/storage.js` — نرمال‌سازی و reconcile لینک‌ها
- `js/app.js` — UI اصلی
